# Kerala Bus — HTML/CSS/JS Website

A responsive single-page recreation inspired by the supplied Kerala private-bus reference image.

## Files

- `index.html` — page structure
- `style.css` — glassmorphism UI, responsive layout and scene styling
- `script.js` — music-player animation and button interactions
- `assets/kerala-scene.jpg` — supplied reference scene used as the visual backdrop

## Run

Open `index.html` directly in a browser, or use VS Code Live Server.

No build tools are required.

## Important

The reference image is used as the background in this version so the visual composition stays close to the supplied design. If you want a truly clean production version, replace `assets/kerala-scene.jpg` with a clean Kerala bus/village background that does not already contain the reference UI.
